============================================================
1. 현재 프로젝트의 최종 방향
============================================================

연구 목표는 단순히 "센서를 붙이면 정확도가 오른다"가 아니다.
현재 가장 방어 가능한 연구 목표는 다음과 같다.

- 비슷한 수어 동작은 MediaPipe 기반 vision-only 모델에서 혼동이 발생한다.
- 스마트 장갑의 Flex 및 IMU 센서 정보는 비전이 놓치는 손가락 굽힘, 손목 회전, 동작 방향 정보를 보완할 수 있다.
- 따라서 비슷한 수어 동작 그룹에서 비전 특징과 센서 특징을 융합했을 때 practical 환경의 인식률이 얼마나 개선되는지 확인한다.

교수님 비교 프레임은 여전히 다음 3축이다.

1. bare hand + vision
2. glove + vision
3. glove + fusion

다만 현재 논문/실험의 중심은 glove 조건에서 vision-only와 fusion을 비교하고, 최종적으로 Feature Redesigned Fusion이 practical 환경에서 더 강하다는 것을 보이는 방향으로 정리되고 있다.

============================================================
2. 중요한 모델 결론 변경
============================================================

이전 2026-04-13 요약에서는 stable hybrid가 가장 안전한 최종 후보처럼 정리되어 있었다.
하지만 2026-04-15 이후 추가 ablation과 2026-04-20 final practical10 multi-seed 평가를 거치면서 결론이 바뀌었다.

현재 최종 모델 구조로 설명해야 하는 것은 다음이다.

- Feature Redesigned Simple Fusion

stable hybrid의 현재 위치:

- 과거에 유망했던 후보 모델
- 비교 실험에 포함되는 candidate/baseline
- 최종 확정 모델이라고 쓰면 안 됨

현재 논문에서 가장 깔끔한 모델 발전 흐름은 다음이다.

1. Vision-only
2. Naive raw fusion
3. Feature Redesigned Fusion
4. Stable hybrid는 추가 후보로 비교했으나 practical 평균에서는 Feature Redesigned Fusion보다 낮았음

핵심 메시지:

- 센서 raw값을 단순히 붙이는 것만으로도 vision-only보다 practical 성능이 좋아졌다.
- 그러나 센서의 물리적 의미에 맞게 특징 구조를 재설계한 Feature Redesigned Fusion이 가장 좋은 practical 평균과 macro F1을 보였다.
- 따라서 최종 모델 설명은 stable hybrid 중심이 아니라 Feature Redesigned Fusion 중심으로 가야 한다.

6. Feature Redesigned Fusion의 실제 입력 구조
============================================================

코드 기준:

- nsu_train.py
- final model config:
  C:\SignProject\experiments\fusion_design_ablation\2026-04-20_final_practical10_seed42_46\seed42\03_feature_redesigned_simple_fusion\config.json

주요 차원:

- Vision feature: 126 dimensions
- IMU feature: 18 dimensions
- State flag feature: 6 dimensions
- Temporal sequence feature per frame: 150 dimensions
  - 126 + 18 + 6 = 150
- Sequence length: 60 frames
- Temporal input shape: 60 x 150
- Flex posture summary feature: 44 dimensions

즉, 최종 입력을 단순히 194차원 시계열이라고 쓰면 부정확하다.
정확한 설명은 다음이다.

- 60프레임 시계열 입력: vision 126 + IMU 18 + state flags 6 = 150차원
- 별도 보조 입력: Flex posture summary 44차원

Feature Redesigned Fusion의 핵심:

- Vision은 손 위치, 형태, 이동 경로를 담당한다.
- IMU는 손의 움직임과 회전 변화를 시간축 정보로 제공한다.
- 상태 플래그는 손 검출 여부, 이전 랜드마크 유지 여부, 손 겹침 여부 등 vision 특징의 신뢰도 상태를 알려준다.
- Flex는 raw 시계열 전체를 그대로 넣지 않고, 하나의 수어 동작 구간에서 나타난 손가락 굽힘 상태를 요약한 posture feature로 사용한다.

Flex posture summary 구성:

- Flex sensor count: 8
- Baseline frames: first 5 frames
- Relative flex sequence: 각 프레임 flex 값에서 초기 baseline 평균을 뺀 값
- Summary components:
  1. mean relative flex: 8 dims
  2. std relative flex: 8 dims
  3. range relative flex: 8 dims
  4. end relative flex: 8 dims
  5. peak absolute relative flex: 8 dims
  6. left-right pair difference based on end relative flex: 4 dims
- Total: 8 + 8 + 8 + 8 + 8 + 4 = 44 dims

논문에서 조심할 점:

- Flex posture summary는 손가락 굽힘의 시간 순서를 완전히 보존하지 않는다.
- 대신 60프레임 동안의 굽힘 정도, 변화폭, 최종 자세, 최대 변화량, 좌우 차이를 요약한다.
- 동작의 시간적 흐름은 vision과 IMU 시계열이 담당하고, flex는 자세/굽힘 상태를 보조하는 구조라고 설명하는 것이 가장 정확하다.

4. 2.3 LSTM
- LSTM을 사용하는 이유를 정리했다.
- 수어는 정적 이미지가 아니라 60프레임 동안 손 위치, 방향, 손가락 굽힘, 이동 경로가 변하는 시계열 데이터라는 점에서 LSTM 필요성을 설명한다.
- RNN의 장기 의존성 한계와 LSTM의 cell state / hidden state / input gate / forget gate / output gate를 설명한다.
- LSTM 수식과 softmax/cross-entropy까지 이어갈 수 있다.

5. 2.6 데이터 융합 및 학습
- 현재 가장 중요한 작성 파트이다.
- 데이터와 특징이라는 용어를 구분해서 쓰기로 했다.
- 수집된 값 자체는 데이터, 모델 입력으로 정리/가공된 값은 입력 특징이라고 쓰는 것이 좋다.
- "융합 데이터"보다는 "융합 특징" 또는 "융합 입력 특징"이 더 정확하다.
- Feature Redesigned Fusion 설명에서 Flex posture summary 수식을 넣는 것이 좋다고 판단했다.

현재 논문 작성에서 추천하는 표현:

- 데이터: 카메라와 센서로부터 수집된 원시 또는 저장 값
- 특징: 모델 입력으로 사용하기 위해 정규화, 추출, 요약된 값
- 융합: 서로 다른 특징을 모델 입력 구조 안에서 결합하는 과정
- Feature Redesigned Fusion: 센서별 물리적 의미에 맞게 입력 특징 구조를 재설계한 융합 방식

발표용 UI 방향:

- 개발자 디버그 값은 숨긴다.
- FINAL RESULT, AI CONFIDENCE, TOP-3, SENSOR GRAPH, STATUS LED 중심으로 간다.
- "Sensor Compensating"처럼 모델 내부에서 직접 검증되지 않은 과장 문구는 피한다.
- 대신 "VISION + GLOVE ACTIVE", "OVERLAP DETECTED"처럼 사실 기반 문구를 쓴다.

13. 절대 헷갈리면 안 되는 표현
============================================================

잘못된 표현:

- stable hybrid가 최종 모델이다.
- Flex raw 시계열을 그대로 최종 모델에 넣었다.
- 최종 입력은 194차원 시계열이다.
- 모든 유사 수어 그룹에서 fusion이 크게 개선되었다.
- 센서가 언제 보정했는지 모델 내부에서 직접 알 수 있다.

정확한 표현:

- 현재 최종 모델은 Feature Redesigned Fusion이다.
- stable hybrid는 비교 후보 모델이다.
- 최종 모델은 60 x 150 시계열 입력과 44차원 Flex posture summary 보조 입력을 사용한다.
- 센서 융합은 특히 순간 손모양 차이형, 방향 차이형, 굽힘/경로 차이형에서 큰 개선을 보였다.
- 일부 그룹에서는 개선이 작거나 하락했으며, 이는 한계로 고찰한다.
- 센서 개입 여부를 직접 추적한다기보다, vision-only와 fusion의 결과 차이로 센서 특징의 기여를 분석한다.
