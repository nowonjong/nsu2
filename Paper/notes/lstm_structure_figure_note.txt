1. 목적
- 2.3 LSTM 절에서 LSTM의 동작 원리를 수식만으로 설명할 경우 가독성이 떨어질 수 있으므로,
  은닉 상태, 셀 상태, 게이트 흐름을 직관적으로 보여주는 개념도를 함께 제시한다.

3. 그림에 반영한 요소
- 입력 x_t와 이전 은닉 상태 h_{t-1}
- 이전 셀 상태 C_{t-1}
- 망각 게이트 f_t
- 입력 게이트 i_t
- 출력 게이트 o_t
- 후보 셀 상태 C~_t
- 셀 상태 갱신 C_t
- 은닉 상태 출력 h_t

4. 논문용 캡션 초안
- 그림 X. LSTM 셀의 구조와 정보 흐름

5. 그림 아래 설명 문장 초안
- 그림 X는 LSTM 셀에서 입력 x_t, 이전 은닉 상태 h_{t-1}, 이전 셀 상태 C_{t-1}가 세 가지 게이트를 거쳐 셀 상태 C_t와 은닉 상태 h_t로 갱신되는 과정을 나타낸다.
  망각 게이트는 이전 정보를 유지할 비율을 결정하고, 입력 게이트는 새롭게 반영할 정보를 선택하며, 출력 게이트는 최종 은닉 상태를 생성한다.

- 추천: 수식 직후에 배치하면, 독자가 식 (1)~(6)과 그림을 함께 보면서 각 게이트의 역할을 더 쉽게 이해할 수 있다.
