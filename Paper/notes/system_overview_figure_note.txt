3. 그림에 반영한 시스템 흐름
- 입력 1. 비전 데이터
  - 웹캠 영상 입력
  - 양손 수어 동작 촬영
  - 실시간 프레임 획득
- 입력 2. 스마트 장갑 데이터
  - 좌/우 손 Flex 센서
  - 좌/우 손 IMU 센서
  - Arduino Mega 기반 센서 수집
  - 시리얼 통신으로 PC 전송
- 비전 특징 추출
  - MediaPipe Hands 적용
  - 손 랜드마크 추출
  - 좌/우 손 추적 및 슬롯 할당
  - 60프레임 시계열 구성
- 센서 특징 구성
  - IMU: temporal sequence 유지
  - Flex: posture-summary feature 변환
  - 기준 프레임 대비 변화량 계산
  - 비전 프레임과 시간축 정렬
- Feature Redesigned Fusion 기반 LSTM
  - vision sequence
  - IMU / flag sequence
  - flex posture feature
  - 멀티모달 융합 및 시계열 학습
- 출력
  - 단어별 신뢰도 산출
  - 최고 신뢰도 단어 선택
  - 실시간 수어 번역 결과 표시

4. 논문용 그림 캡션 초안
- 그림 X. 실시간 수어 인식 및 번역 시스템의 전체 구성도

5. 그림 아래 설명 문단 초안
- 그림 X는 본 연구에서 구현한 실시간 수어 인식 및 번역 시스템의 전체 구성을 나타낸다.
  시스템은 웹캠을 통해 획득한 비전 데이터와 스마트 장갑으로부터 수집한 Flex 및 IMU 센서 데이터를 동시에 입력받는다.
  비전 데이터는 MediaPipe Hands를 통해 손 랜드마크 기반 특징으로 변환되며, 센서 데이터는 Arduino Mega와 시리얼 통신을 통해 PC로 전송된다.
  이후 두 입력은 Feature Redesigned Fusion 기반 LSTM 모델에 입력되어 각 단어에 대한 신뢰도를 산출하고, 최종적으로 가장 높은 신뢰도의 결과를 실시간으로 출력한다.

6. 배치 추천

- 역할: 이후 세부 절(하드웨어, MediaPipe, LSTM, 데이터 수집, 데이터 융합)의 전체 연결 관계를 먼저 제시하는 개요 그림으로 사용
